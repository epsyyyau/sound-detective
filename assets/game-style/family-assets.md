# Word-Family Cottage Assets

Generated 2026-10-10 with built-in ImageGen, using `assets/family-map/route-signless.png` as a style reference. Original artwork remains unchanged.

## Saved Assets

- `assets/game-style/family-house.png`: transparent, blank-sign cottage. The game overlays letters and a roof-only recolour layer using shared group palette filters.
- `assets/game-style/family-background.png`: opaque garden courtyard for question and completion screens.

## Final Prompt Set

### Cottage

Use case: stylized-concept. Transparent game cottage sprite matching the soft miniature clay 3D cottages on the route map. One isolated front-facing cream cottage with pastel golden-yellow roof, small coral chimney, tiny blue windows, rounded terracotta arched door, two green shrubs and white daisies at base. Matte rounded edges, gentle shadows, no dark cartoon outlines or face. Wide empty white rectangular sign centered on the facade for dynamic letters. Unobstructed sign, centered door below it. Square canvas with small transparent margins. Actual transparent background; no ground plane, scenery, text, letters or watermark.

### Garden

Use case: stylized-concept. Wide 16:9 full-bleed village garden background matching the map's miniature clay 3D palette. Pale butter-yellow central area and mint/sage meadows; curved cream footpath along the foreground; rounded trees, bushes, white daisies and a white picket fence only at the edges. Center 65% and upper center uncluttered for overlaid cottage, heading, options and controls. Gentle diorama lighting, matte textures and soft depth. Opaque; no central buildings, text, letters, numbers, trains, characters, watermark or UI.
