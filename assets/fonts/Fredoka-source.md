# Fredoka

Source: https://github.com/google/fonts/tree/main/ofl/fredoka

Original variable font: Fredoka[wdth,wght].ttf, downloaded 2026-10-11.
Stored locally as Fredoka-variable.ttf without altering the font.
License: SIL Open Font License 1.1; see Fredoka-OFL.txt.

The font approximates the rounded lettering in the generated cargo-station
reference image. The illustration is not an exact typeface identification.
Chinese text continues to use the existing Huninn Chinese font.
